EduMind with login tracking
1. Install Node.js (v18+): https://nodejs.org
2. In this folder run:  npm install   then   npm start
3. Open http://localhost:3000  and sign in as admin / admin123 (change these!)
4. Students click "New student? Sign up". Admin/teacher sees the "Login activity" tab.
To let others use it, deploy this folder to Render, Railway or a VPS. Logins are saved in data.json.
